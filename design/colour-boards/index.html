Colour direction — two boards to choose from

Both boards use the same layout, same typefaces, same words. The only thing that changes between them is colour. That is deliberate: it keeps this decision about colour and nothing else. Layout, imagery, and copy all come later.

The brief was authoritative, warm, institutional — not corporate-cold, and specifically not the pink/lavender palette most POSH websites default to. That styling reads as soft and quietly undermines the legal expertise you are actually selling.

What we need from you

  1. Open this file in a browser and scroll through both boards.
  2. Pick Board A or Board B. Please pick one rather than asking to mix them — the accent and background are tuned to the primary in each.
  3. Tell us anything that feels wrong, in plain words. "Too dark", "too corporate", "the orange is doing too much" are all useful.
  4. Reply by end of this week. Every page we build afterwards inherits this decision, so changing it later means redoing work.

Is a home office a "workplace" under the Act?

Yes. The definition of workplace in the Act is deliberately broad, and it extends to any place visited by an employee arising out of or during the course of employment — which includes work carried out from home under a remote arrangement.

This matters for the Internal Committee, because a complaint arising from a remote working arrangement follows exactly the same process and the same statutory timelines as one arising on the employer's premises. See the section on Internal Committee constitution.

Readability check

Every pairing below was measured against WCAG 2.1 AA, the accessibility standard we are building to. Normal text needs 4.5:1; text at 18px and above needs 3:1. This is not box-ticking — it is what makes the site readable on a phone in poor light, which is where a lot of your traffic will be.

One change we recommend either way. In Board A, a CTA button with white text on amber measures 3.29:1 and fails the standard. Using Ink text on amber instead measures 5.40:1 and passes at any size — so the amber stays exactly as you see it, and only the label colour changes. Every amber button in Board A above already uses the corrected version. If you pick Board B, we would nudge Clay one step darker to #A94F2E for the same reason.
